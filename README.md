# Online MCQ Examination Platform

A production-oriented Online MCQ Examination Platform with:

- Android Mobile App
- Public Website
- Admin Panel
- Secure Backend/API
- PostgreSQL Database
- SMS OTP registration
- Question and Exam Management
- Timed MCQ Examination
- Result, Merit and Leaderboard
- Subscription and Package Management
- bKash / Nagad / SSLCommerz payment architecture
- Notifications and Reports

## Current Status

Project initialization and requirement analysis stage.
